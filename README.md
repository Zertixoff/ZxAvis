# ⭐  • ZxAvis
Plugin pour le jeu : Nova-Life : Amboise

# 📦 Fonctionnalités

En tant que STAFF, via la commande `avis`, d'ouvrir un menu au joueur le plus proche afin de lui proposer de déposer un avis sur votre prestation : 

- Note
- Commentaire

Quand le joueur a fini de noter, un webhook est envoyé via le webhook configuré dans la config (`AvisConfig.json`) toujours dans le dossier `ZxPlugins`
 
# 📚 Conditions d’utilisation

*Le code source de ce plugin est privé.*

- **Interdiction de décompiler ce plugin**  
- **Interdiction de se l’approprier**

# ⚒️ Utilisation

Depuis le GitHub, téléchargez le fichier **.dll** du plugin.  
Placez ensuite ce fichier dans votre dossier `Plugins`.  
Configurez la configuration (dans le dossier `ZxPlugins`, fichier `AvisConfig.json`).  

Lancez votre serveur, et le plugin sera fonctionnel.  
Si cela ne fonctionne pas, merci de me mentionner sous ce post.



***Ce plugin ne possède pas de dépendances.***
